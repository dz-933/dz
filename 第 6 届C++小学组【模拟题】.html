三、编程题（每题20分，共2题，40分）

T1：糖果大派送

题目描述：

运动会上，班长小明箱子里拿着 2026 颗糖果。

按照游戏规则依次邀请同学上来操作：

第 1 位同学拿走 1 颗糖果（-1），

第 2 位同学放回 2 颗糖果（+2），

第 3 位同学拿走 3 颗糖果（-3），

第 4 位同学放回 4 颗糖果（+4）……

以此类推。

奇数编号的同学拿走对应数量糖果，偶数编号的同学放回对应数量糖果。

一共轮到第 n 位同学操作结束。

请问最后班长小明箱子里还剩下多少颗糖果？

数学式子：2026 -1 +2 -3 + 4 - ........ ±n

规则：遇到奇数就减，偶数就加。

 

输入描述

输入一行，正整数 n。

 

输出描述

输出一行，为班长小明箱子里还剩下多少颗糖果。

 

输入输出样例

输入样例 1

xxxxxxxxxx
12

输出样例 1

xxxxxxxxxx
2032

输入样例 2

xxxxxxxxxx
6

输出样例 2

xxxxxxxxxx
2029

 

参考代码

xxxxxxxxxx
#include <iostream>
using namespace std;
int main(){
    int number,sum,i = 1;  
    //number是输入的数字,i是变量,sum是求和 
    cin>>number;
    sum = 2026; 
    while ( i <= number )
    {
        if( i % 2 == 1 )  
        {    sum -= i;}
        else
        {    sum += i;} 
        i ++;
    }
    cout<<sum<<endl;
    return 0;
}

 

 

 

T2：探险小队要闯关

题目描述

小明所在的探险小队里一共有 n 名队员完成了闯关挑战，每位队员都会获得一个闯关得分。队长想要知道小队里谁的闯关分数最高，请你编写程序算出最高分。

输入描述

输入共两行：

第一行输入整数 n（1≤n<100）代表探险队员人数。

第二行输入 n 个整数，依次为每位队员的闯关得分，相邻分数用空格隔开，分数取值范围 0~100。

输出描述

输出一个整数，代表全队最高闯关分数。

输入输出样例

输入样例 1

xxxxxxxxxx
5
85 78 90 99 60

输出样例 1

xxxxxxxxxx
99

输入样例 2

xxxxxxxxxx
4
89 64 0 78

输出样例 2

xxxxxxxxxx
89

 

参考代码 1

xxxxxxxxxx
#include <iostream>
using namespace std;


int main()
{
    int n;
    // 读取探险队员总人数
    cin >> n;


    int max_score;
    int score;
    // 先读取第一个队员分数，作为当前最高分初始值
    cin >> max_score;


    // 循环读取剩下 n-1 名队员的分数
    for (int i = 2; i <= n; i++)
    {
        cin >> score;
        // 如果当前队员分数比记录的最高分更高，更新最高分
        if (score > max_score)
        {
            max_score = score;
        }
    }


    // 输出全队最高闯关得分
    cout << max_score << endl;
    return 0;
}

参考代码 2

xxxxxxxxxx
#include <iostream>
using namespace std;


int main()
{
    int n;
    cin >> n;
    int a[105];  // 存放所有队员分数


    // 读取全部分数存入数组
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
    }


    int max_score = a[0];
    // 遍历数组寻找最大值
    for (int i = 1; i < n; i++)
    {
        if (a[i] > max_score)
        {
            max_score = a[i];
        }
    }


    cout << max_score << endl;
    return 0;
}
